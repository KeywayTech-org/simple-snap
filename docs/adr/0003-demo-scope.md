# 0003 — Demo 范围与不做项

- 状态: 接受
- 日期: 2025-09-03
- 范围: Demo v1

## 背景

第一版目标是**展示核心链路能跑通**，不是产品化。任何与"核心链路"无关的功能（账号、存储、分享、付费、运营）一律延后。

## 决策

**Demo v1 范围**：

- ✅ 客户端：上传源照片、三阶段进度、结果展示、创作思路、下载到本地、重做（带选项抽屉）、失败 Toast
- ✅ 后端：单接口 `POST /api/poster`，接收（源照片 + 选项）→ 返回（作品图 + 创作思路）
- ✅ 选项：高纯度色、文字语言、微文本

**Demo v1 不做**：

- ❌ 用户账号 / 登录 / 鉴权（无状态接口）
- ❌ 任何持久化（无数据库、无对象存储、无缓存）
- ❌ 历史作品 / 我的作品
- ❌ 分享链接 / 邀请
- ❌ 付费 / 配额
- ❌ 内容安全前置扫描
- ❌ 营销页 / Hero / 介绍页（落地即上传）
- ❌ 多尺寸（仅 3:5 竖版）

## 后果

- **正**:
  - PRD 可在一天内写完。
  - 实施可在数天内完成。
  - 失败成本极低（没有数据/账号需要迁移）。
- **负**:
  - 任何用户行为（除了下载到本地）都不会被记住——Demo 阶段可接受。
  - 同一用户第二次访问=全新用户。
  - 客户问"我的作品呢"=没这个功能。
- **可逆性**: 高。Demo 验证通过后再逐项添加。

## 升级路径

按以下顺序增量：

1. 接入微信 H5 鉴权（用户绑定）
2. OSS 持久化 + 我的作品列表
3. 内容安全前置扫描
4. 分享链接
5. 付费 / 配额
6. 多尺寸（横版 / 方版）
